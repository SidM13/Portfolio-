# Portfolio Version 2

The redesigned portfolio is stored in [`version-2/`](version-2/).

This branch is intentionally **not** the GitHub Pages production source. The current published portfolio remains on the `main` branch at <https://sidm13.github.io/>.

## Local development

```bash
cd version-2
pnpm install
pnpm dev
```

## Verification

```bash
pnpm test
pnpm build
```

Switch GitHub Pages or merge this branch only when Version 2 is ready to publish.
